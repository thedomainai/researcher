# Evaluating Quantum Support Vector Machine for Multiclass Student Performance Prediction: A Comparative Analysis with Machine Learning and Deep Learning Models

**著者**: Abdul Rohman, Nova Rijati, Pujiono, Ahmad Zainul Fanani
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: オペレーションズリサーチ

## Abstract

Student performance prediction plays an important role in higher education by supporting early intervention, dropout prevention, and academic decision-making.This study evaluates the effectiveness of Quantum Support Vector Machine (QSVM) for multiclass student performance prediction through a comprehensive comparison with conventional Machine Learning (ML), ensemble learning, and Deep Learning (DL) models.The proposed framework was evaluated using a real educational dataset comprising 7,499 student records from a private university in Indonesia, categorized into Active, Graduated, and Dropout classes.Data preprocessing included label encoding, feature standardization, train-test splitting, Synthetic Minority Oversampling Technique (SMOTE), and Principal Component Analysis (PCA).QSVM employed quantum feature mapping and fidelity-based quantum kernels implemented using the PennyLane quantum simulation platform.Comparative experiments involved Logistic Regression, K-Nearest Neighbor, Decision Tree, Support Vector Machine, Random Forest, XGBoost, LightGBM, CatBoost, and Artificial Neural Network (ANN).Model performance was assessed using Accuracy, Macro Precision, Macro Recall, Macro F1-score, Macro AUC (OvR), stratified 10-fold cross-validation, and statistical significance tests.Cross-validation results showed that LightGBM achieved the highest predictive performance and the most robust generalization capability across validation folds.QSVM remained competitive but consistently ranked below LightGBM, XGBoost, Random Forest, and CatBoost.The paired t-test and Wilcoxon signed-rank test revealed statistically significant differences between QSVM and all evaluated models except CatBoost, whereas the Friedman test confirmed significant overall differences among the ten evaluated classifiers (χ² = 81.5207,p = 8.06 × 10⁻¹⁴).The findings indicate that QSVM provides competitive predictive capability for multiclass student performance prediction but does not surpass state-of-the-art ensemble learning methods.The primary contribution of this study is a comprehensive and statistically validated benchmarking framework that systematically compares Quantum Machine Learning, conventional Machine Learning, ensemble learning, and Deep Learning models under identical preprocessing and evaluation protocols, providing a practical benchmark for future research in quantum-enhanced educational analytics.
