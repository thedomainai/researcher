# An AI-Driven Multi-Camera Stereo Vision Framework for Real-Time 3D Human Movement Tracking, Biomechanical Analysis, and Sustainable Performance Optimization

**著者**: Zoltán Kaszai, Ákos Kovács
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: オペレーションズリサーチ

## Abstract

This project aims to introduce an AI-driven, multi-camera stereo vision system for real-time, high-precision 3D human motion tracking and analysis. The platform combines image and depth data from a network of stereo cameras into a single spatial reference coordinate system. It uses advanced human pose estimation, motion tracking, and data fusion for later biomechanical analysis to measure movement features like gait, posture, balance, and symmetry. The system supports objective assessment of human motion and helps identify abnormalities or functional limitations through continuous monitoring. Its main contribution is a robust, scalable framework for accurate 3D motion reconstruction for quantitative and objective movement analysis. This technology can be used in healthcare, rehabilitation, ergonomics, sports science, and research, providing reliable, non-invasive human motion data for better decision-making.
