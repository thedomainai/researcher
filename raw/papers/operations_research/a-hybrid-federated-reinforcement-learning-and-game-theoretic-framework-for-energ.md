# A Hybrid Federated Reinforcement Learning and Game-Theoretic Framework for Energy-Aware Clustering and Fault Diagnosis in IoT-Enabled Wireless Sensor Networks

**著者**: Lateef Abd Zaid Qudr
**年**: 2026 | **被引用数**: 0

## Abstract

This repository provides the complete reproducibility package associated with the research study entitled “A Hybrid Federated Reinforcement Learning and Game-Theoretic Framework for Energy-Aware Clustering and Fault Diagnosis in IoT-Enabled Wireless Sensor Networks.” The package contains the source code, simulation scripts, network and experimental configuration files, execution scripts, seed manifest for 20 independent experimental runs, model architecture and trained-model files, raw experimental results organized by run and method, statistical analysis scripts, plotting utilities, unit tests for constraint verification, and the software environment specifications required to reproduce and verify the reported experimental results. The proposed framework integrates Federated Learning (FL), Reinforcement Learning (RL), Game-Theoretic (GT) decision mechanisms, fault diagnosis, and adaptive sleep scheduling to support energy-efficient cluster-head selection and reliable operation in IoT-enabled Wireless Sensor Networks (WSNs). The provided implementation also includes the baseline methods used for comparative evaluation and the scripts required to regenerate the experimental datasets, execute the experiments, calculate the evaluation metrics, perform statistical analyses, and reproduce the figures reported in the study. The experimental environment is based on Python 3.11, TensorFlow 2.17/Keras, NumPy 1.26, SciPy 1.11, scikit-learn 1.4, Pandas 2.0, and Matplotlib 3.8, with a Docker specification provided to facilitate software and operating-system reproducibility. The repository is intended to support independent verification, reproducibility, and further research on intelligent, energy-aware, and fault-resilient clustering mechanisms for IoT-enabled WSNs. Repository contents include: complete simulation source code; configuration files and experimental parameters; one-command reproduction scripts; 20-run random-seed manifest and seed derivation; FL and RL model files; per-run and per-method experimental results; statistical validation and analysis scripts; figure-generation scripts; unit and constraint-verification tests; and Docker and dependency specifications. Reproducibility: The included documentation provides instructions for configuring the execution environment and rerunning the experimental workflow. The package is organized to enable researchers to reproduce the simulations, inspect intermediate and raw outputs, regenerate the reported performance metrics and figures, and independently evaluate the proposed framework.
