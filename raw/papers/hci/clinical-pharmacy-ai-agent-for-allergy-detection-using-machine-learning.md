# Clinical Pharmacy AI Agent for Allergy Detection Using Machine Learning

**著者**: Christelle Raad, Tarek Barhoum
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: HCI

## Abstract

This project develops a clinical pharmacy decision support system focused on analyzing prescriptions to improve medication safety. An AI model checks new prescriptions against a patient’s medication history and known allergies, generating safety alerts. The system centralizes prescription data for doctors and pharmacists while ensuring that AI functions strictly as a support tool, not a decision-maker. This work was conducted at Arab International University (AIU), Syria. The official website of the university is: https://www.aiu.edu.sy (https://www.aiu.edu.sy/)
