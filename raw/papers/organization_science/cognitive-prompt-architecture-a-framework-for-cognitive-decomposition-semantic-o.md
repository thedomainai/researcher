# Cognitive Prompt Architecture: A Framework for Cognitive Decomposition, Semantic Organization, and Complex Instruction Design in Human–AI Interaction

**著者**: Roman Shaban
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 組織科学

## Abstract

The increasing complexity of human interaction with large language models (LLMs) requires a transition from conventional prompt formulation toward systematic approaches to instruction architecture. Although prompt engineering has traditionally emphasized linguistic precision, contextual specification, and iterative refinement, complex tasks also demand structured representations of cognitive operations, conceptual dependencies, semantic relationships, and uncertainty. This paper introduces Cognitive Prompt Architecture (CPA), a proposed methodological framework for designing prompts through cognitive decomposition and semantic organization. CPA conceptualizes prompt development as a process of transforming an initially complex or insufficiently structured task into an organized system of cognitive operations, conceptual hierarchies, semantic relationships, execution rules, and evaluation criteria. The proposed framework integrates principles from cognitive psychology, knowledge representation, concept mapping, task analysis, and contemporary prompt-engineering research. The paper presents a seven-stage methodology encompassing task analysis, cognitive decomposition, semantic architecture, conceptual hierarchization, concept mapping, ambiguity management, instruction synthesis, and systematic evaluation. It further introduces a reusable prompt architecture, illustrates its application through a complex decision-support scenario, and outlines criteria for evaluating architectural quality. The central proposition is that effective prompt engineering should address not only how instructions are linguistically expressed but also how the underlying intellectual task is represented, decomposed, and reconstructed for human–AI collaboration. CPA is presented as a conceptual and practical framework whose comparative effectiveness requires empirical validation
