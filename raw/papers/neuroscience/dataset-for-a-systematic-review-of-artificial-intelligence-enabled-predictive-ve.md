# Dataset for a systematic review of artificial-intelligence-enabled predictive vehicle suspension: search strategy, screening log, study coding and figure source data

**年**: 2026 | **被引用数**: 0

## Abstract

This dataset supports the systematic review "From Road Perception to Learning-Based Control: A Systematic Review of Artificial-Intelligence-Enabled Predictive Vehicle Suspension". It contains the exact Scopus search strings; a screening log of all 617 retrieved records with the decision and exclusion reason for each; the coding sheet of the 39 included studies (function in the perception-to-control chain, method family, validation level, perception–control integration and key reported outcome); and the source data for the tables and figures of the article. Scopus abstracts are not redistributed; all records can be retrieved through the DOIs provided. A README describes every file and variable.
