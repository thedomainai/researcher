# Fusion-aware Ensemble Learning for Robust Multimodal Epileptic Seizure Detection Under Cross-dataset Distribution Shifts

**著者**: Abdul-Mumin Khalid, M. Sulemana, Wahab Abdul Iddrisu
**年**: 2026 | **被引用数**: 0
**タイプ**: meta_analysis | **分野**: 脳科学

## Abstract

Epileptic seizure detection using machine learning has promising results on benchmark datasets; reliable generalization to real-world clinical environments remains challenging due to inter-patient variability, sensor heterogeneity, and dataset shift.To address this limitation, this study proposes a fusion-aware decision-level ensemble learning framework for multimodal epileptic seizure detection using synchronized electroencephalography (EEG), electrocardiography (ECG), electromyography (EMG), and accelerometer (ACC) signals.Twelve heterogeneous machine-learning and deep-learning models are trained on a unified multimodal dataset under strict patient-wise data partitioning to prevent data leakage.Classical ensemble strategies, including voting, bagging, boosting, and stacking, are systematically evaluated and compared with the proposed fusion-aware ensemble, which jointly optimizes multimodal fusion parameters and ensemble aggregation weights.We validated the proposed framework using multimodal data obtained from Tamale Teaching Hospital and the OpenNeuro public dataset.Following patient selection, the combined dataset was partitioned using a strict patient-wise 70% training, 15% validation, and 15% unseen testing protocol.The final 15% patient-wise hold-out subset was reserved exclusively for final evaluation to assess model generalization without patient overlap.Experimental results indicate that the proposed method achieved 97.25% accuracy and 99.60% AUC on unseen data, and 95.25% accuracy with 99.00% AUC on the Patient-wise Unseen Test Dataset.These findings indicate that the proposed framework has strong potential for reliable multimodal seizure detection under realistic patient-wise unseen deployment scenarios and demonstrates strong discriminative capability on previously unseen patients.The results suggest that the proposed fusion-aware ensemble framework provides robust and reliable seizure detection under strict patient-wise evaluation.
