# Integrating AI into DevSecOps: Enhancing CI/CD Security with Intelligent Automation

**著者**: Achref Rhouma
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 脳科学

## Abstract

This paper presents a practical framework for integrating Artificial Intelligence (AI) into DevSecOps pipelines to enhance CI/CD security. It demonstrates AI-driven vulnerability detection, anomaly-based monitoring, and predictive risk scoring, with code examples and practical recommendations for cloud-native environments.
