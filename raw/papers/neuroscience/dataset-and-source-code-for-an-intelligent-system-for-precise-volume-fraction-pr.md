# Dataset and Source Code for: An Intelligent System for Precise Volume Fraction Prediction in Stratified Three-Phase Flow Using Optimized Artificial Intelligence Models

**著者**: M. Emamian
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 脳科学

## Abstract

This repository contains the dataset and Python source code utilized in the study for predicting volume fractions in stratified three-phase (gas-oil-water) flow. The dataset, generated via an experimentally validated Finite Element Method (FEM) model in COMSOL Multiphysics, includes 16 capacitance features extracted from an 8-blade sensor across 66 distinct physical fluid distributions. The codebase features the implementation and hyperparameter tuning of five distinct machine learning models (MLP, RBF, RF, KNN, and XGBoost), along with the physical boundary-condition enforcement algorithms.
