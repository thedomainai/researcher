# Systematized Machine Delusion: Premise Substitution and Naturalization Drift in Reasoning Models

**著者**: B.Y. Hughes Graduate Student
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 脳科学

## Abstract

This paper introduces the concept of Systematized Machine Delusion, a distinct failure mode in modern reasoning-oriented artificial intelligence systems. Unlike conventional hallucination, which arises from localized generation errors while the underlying interpretive structure remains intact, systematized machine delusion emerges when a model recursively substitutes its own generated premises for the original user constraints and subsequently constructs internally coherent but empirically detached reasoning chains. Building upon the Unified Complementation Framework (UCF) and Fantasy Generation Theory (FGT), the paper formalizes two key mechanisms: Premise Substitution ($x_0 \rightarrow \hat{x}_0$) and Naturalization Drift ($N^{(0)} \rightarrow N^{(T)}$). To quantify this phenomenon, a novel metric, the Constraint Preservation Error (CPE), is introduced as a benchmark for evaluating the degradation of original user constraints across extended reasoning horizons. Drawing on information-theoretic analogies to Solomonoff induction, predictive coding, and computational psychiatry, the study argues that informationally closed reasoning systems are vulnerable to recursive epistemic drift. The paper further proposes architectural countermeasures, including exogenous grounding, specialist-verified multi-agent systems, and provenance-weighted attention mechanisms designed to preserve fidelity to original constraints. The work distinguishes hallucination, deception, sycophantic amplification, and systematized machine delusion as structurally different computational phenomena and provides a formal framework for analyzing premise drift in next-generation reasoning models.
