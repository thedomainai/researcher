# Intelligent LiDAR-Based Aircraft Stall Margin Prediction Using Artificial Intelligence and Sensor Fusion Under Atmospheric Turbulence

## Abstract

AI-Based Aircraft Stall Margin Prediction Using Forward-Looking LiDAR and Machine Learning This repository presents a research project investigating the feasibility of predicting aircraft stall conditions through the integration of forward-looking LiDAR sensing, conventional flight telemetry, sensor fusion, and machine learning techniques. The proposed system aims to estimate an aircraft's remaining stall margin by detecting atmospheric disturbances ahead of the aircraft and combining these observations with real-time flight parameters, including airspeed, angle of attack, pitch, roll, and altitude. Unlike conventional stall warning systems, which primarily provide reactive alerts when the aircraft is already approaching critical flight conditions, this research explores a predictive approach capable of estimating changes in effective angle of attack before hazardous conditions develop. The project demonstrates a conceptual architecture combining LiDAR-based airflow sensing, embedded data acquisition, AI-based prediction models, and a cockpit decision-support interface. The repository contains the complete research documentation, system architecture diagrams, hardware design concepts, Python source code, simulation examples, and supporting engineering materials developed as part of an independent aerospace engineering research project.
