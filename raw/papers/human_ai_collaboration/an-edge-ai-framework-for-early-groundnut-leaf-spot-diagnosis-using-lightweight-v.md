# An Edge AI Framework for Early Groundnut Leaf Spot Diagnosis Using Lightweight Vision Transformers

**著者**: Parthasarathy Seethapathy, Kannan M, Manivasagam V.S., G. Gopakumar
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 人間-AI協働

## Abstract

Plant disease detection is essential for improving crop productivity, ensuring food security, and supporting sustainable agricultural practices. This study presents an edge AI framework using lightweight vision transformer for early and stage-specific groundnut leaf spot disease detection. An Attention-Augmented Lightweight Mobile Vision Transformer (AAL-MobileViT) framework is proposed by integrating spatial and channel attention mechanisms with the MobileViT backbone to improve lesion-focused feature representation and classification performance. The proposed framework was evaluated against multiple lightweight convolutional neural network (CNN) and base-line MobileViT models. A total of 6,210 real-time groundnut leaf images belonging to three classes, namely early leaf spot, healthy, and late leaf spot, were utilized for model training and evaluation. The experimental results confirmed that the proposed AAL-MobileViT model performs better than the other models by 94.88\% classification accuracy on the test set. In addition, several experiments using seeds and an out-of-distribution (OOD) test proved stable learning behavior and increased stability to an external field dataset. For practical agricultural use, a real-time mobile application called ~''Amrita Crop Care''~ was developed, to enable the diagnosis of diseases using the smartphone and give appropriate recommendations. The process of statistical verification, cross-location validation, and smartphone deployment exhibits the practical usefulness of the proposed framework for field-level groundnut leaf spot diagnosis.
