# Time-step targeting methods for real-time dynamics using the density matrix renormalization group

**著者**: Adrian E. Feiguin, Steven R. White
**年**: 2005 | **被引用数**: 194
**タイプ**: primary | **分野**: 計算物理学

## Abstract

We present a time-step targeting scheme to simulate real-time dynamics efficiently using the density matrix renormalization group. The algorithm works on ladders and systems with interactions beyond nearest neighbors, in contrast to existing Suzuki-Trotter-based approaches.
