# Spin Gaps in a Frustrated Heisenberg Model for CaV4O9

**著者**: Steven R. White
**年**: 1996 | **被引用数**: 250
**タイプ**: primary | **分野**: 計算物理学

## Abstract

I report results of a density matrix renormalization group (DMRG) study of a model for the two-dimensional spin-gapped system ${\mathrm{CaV}}_{4}{\mathrm{O}}_{9}$. This study represents the first time that DMRG has been used to study a two-dimensional system on large lattices, in this case as large as $24\ifmmode\times\else\texttimes\fi{}11$, allowing extrapolation to the thermodynamic limit. I present a substantial improvement to the DMRG algorithms which makes these calculations feasible.
