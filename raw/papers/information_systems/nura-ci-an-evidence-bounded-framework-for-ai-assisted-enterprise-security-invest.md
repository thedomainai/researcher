## Abstract

NURA-CI: An Evidence-Bounded Framework for AI-Assisted Enterprise Security Investigation Technical Research Report | 2026 | Non-Peer-Reviewed This technical report presents NURA-CI, an evidence-bounded security investigation framework developed as part of NURA, an enterprise AI assistant project aimed at improving IT and cybersecurity investigations through intelligent automation. NURA aims to integrate enterprise systems, support security investigations, and assist IT teams through natural-language interaction. Within this vision, NURA-CI introduces six stages: Normalize, Understand, Reason, Act, Confirm, and Improve, emphasizing evidence-based conclusions, authorization controls, and trustworthy AI-assisted investigations. The research demonstrates a prototype integrating Microsoft Graph, Exchange Online, and Barracuda Email Gateway, evaluated through six controlled security investigation scenarios. This report documents the initial research, architecture, implementation, and findings of NURA-CI, shared to encourage further exploration of AI-assisted enterprise cybersecurity.
