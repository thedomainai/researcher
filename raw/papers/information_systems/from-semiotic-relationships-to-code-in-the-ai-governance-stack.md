# From Semiotic Relationships to Code in the AI Governance Stack

**著者**: Lara Stuart
**年**: 2026 | **被引用数**: 0

## Abstract

This diagram maps Ferdinand de Saussure's two-part sign model — signifier and signified — onto a six-layer AI governance architecture. It demonstrates that AI systems operate on signs, not truths, and that governance must ensure every transformation from human intent to system state change remains admissible, traceable, and aligned with intent, policy, and law. The six layers — Human Intent, Signifier, Model Processing, Signified, Code Generation, and Execution and State — are mapped to corresponding technical representations and governance control functions including intent capture, input validation, model boundary controls, semantic validation, execution gating, and immutable audit. The semiotic chain through the stack illustrates key governance principles: arbitrary relationship requiring admissibility definition, meaning through difference requiring context integrity, stability through agreement, inevitability of drift requiring continuous monitoring, and liability following the sign chain.
