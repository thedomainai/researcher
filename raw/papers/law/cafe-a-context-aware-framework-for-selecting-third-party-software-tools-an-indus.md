# CAFE : a context-aware framework for selecting third-party software tools: an industrial case study of web API fuzzing

**著者**: Alma Oručević-Alagić, Karl Alemo, Fredrik Orheim, Per Runeson, Victoria Vucic
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 法学

## Abstract

Background: Industrial adoption of third-party software tools requires more than technical performance evaluation, yet selection methods often underrepresent integration and organizational constraints. Objective: We develop CAFE, a context-aware framework for eliciting, assessing, and synthesizing tool selection requirements. Method: Following a Design Science Research approach, CAFE was developed using literature and evidence from an industrial web API fuzzing tool selection project in an embedded systems organization. The case involved stakeholder interviews, focus groups, benchmarking, proof of concept integration, documentation and security reviews, and practitioner feedback.Results: CAFE structured requirements across technical, integration and operational, and organizational and contextual dimensions. Selection depended not only on technical performance but also on project maturity, security, maintainability, and integration feasibility. Conclusions: CAFE supports traceable and context sensitive tool selection by linking stakeholder requirements to heterogeneous evidence. The study highlights the limitations of performance centric evaluation in security and safety critical environments.
