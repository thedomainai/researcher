# Simulation code for "Real-Time AI Service Economy: A Framework for Agentic Computing Across the Continuum"

**著者**: Lauri Lovén, Alaa Saleh, Reza Farahani, Ilir Murturi, Sujit Gujar
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 行動経済学

## Abstract

R + targets pipeline reproducing the experiments in the arXiv preprint arXiv:2603.05614, "Real-Time AI Service Economy: A Framework for Agentic Computing Across the Continuum": the topology x load ablation grid, the DSIC strategic-bidding test, a measured agentic LLM workload, and the integrator faithfulness and encapsulation-overhead studies. Reproduce all results with targets::tar_make().
