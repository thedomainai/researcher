# Can TDD improve the quality of LLM-migrated code? : A pilot study in an industrial context

**著者**: Emelie Tingberg, Victor Sannicolo, Per Runeson, Ivan Aladjoff
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 行動経済学

## Abstract

The emergence of Large Language Models (LLM) has created new possibilities for automating software development, yet ensuring the quality of AI-generated code remains a major challenge. We aim to investigate if Test-Driven Development (TDD) can improve the quality of code generated by an LLM in a fully autonomous context, within a pilot project at Decerno AB. We added TDD to their pilot workflow, using a design science approach, with continuous refinements to prompt design and workflow structure, based on observed AI behavior. The generated code was evaluated and compared with non-TDD code, using SonarQube for static code analysis. The results indicate that TDD reduced complexity and code duplication, but introduced more quality issues overall, while non-TDD produced fewer, but more severe issues. The generated tests from the TDD workflow focused more on content verification than on behavioral testing, contributing to a lower code coverage per test compared to non-TDD. The findings suggest that TDD involves trade-offs that may favor certain development priorities, in particular where lower complexity and reduced duplication are more beneficial than minimizing total issue count. This indicates that a strict application of TDD may not be optimal in an autonomous AI-driven context, and that exploring more flexible adaptations of the TDD workflow remains interesting for future research.
