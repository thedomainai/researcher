# AI Safety and Reliability Auditing: DistilBART Zero-Shot Pipeline for Human–Robot Interaction

**著者**: Wing Lam Tsang
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 会計学

## Abstract

This repository contains the Python implementation and diagnostic auditing pipeline using the zero-shot classifier DistilBART-MNLI (valhalla/distilbart-mnli-12-1) to evaluate Artificial Intelligence (AI) safety and model reliability in Human–Robot Interaction (HRI). The code audits multi-turn conversational trajectories between elderly users and care robots to detect operational failures and ethical risks across four core failure domains: Technical Latency, Dialogue Tracking, Social Norm Violation, and User Autonomy Infringement. Designed for resource-constrained edge computing evaluation, it features a 2x2 diagnostic analytics dashboard that generates normalised confusion matrices, category-level F1-score comparisons, prediction bias reports, precision-recall tables, and automated CSV exports of misclassified interaction logs (audit_errors.csv) for AI reliability auditing.
