# Emergence-Driven Security of LLM Agents

**著者**: Nektaria Kaloudi, Georgios Kavallieratos, Georgios P. Spathoulas, Sokratis K. Katsikas
**年**: 2026 | **被引用数**: 0
**タイプ**: primary | **分野**: 複雑系科学

## Abstract

Large language model (LLM) agents are no longer limited to text generators, but they can also plan, call tools, delegate tasks to other agents, act within external environments, and change states in response to their actions. In Anthropic's recent report on an AI-orchestrated cyber-espionage campaign involving Claude Code, individual subtasks appeared legitimate when evaluated in isolation but became malicious when combined into an autonomous attack sequence.Consequently, the security of such complex LLM-based agentic systems may fail even when each component appears secure in isolation. This position and open-problem paper argues that LLM agent security should be studied as emergence-driven security: the analysis of security properties that arise from the interactions among agents and its components over time. We define emergence-driven security and provide a conceptual taxonomy to classify emergent security-related phenomena in LLM agents, covering both beneficial and harmful forms of emergence.Based on these insights, we propose EASE, an Emergence-Aware Security Evaluation framework that provides a systematic process for assessing how interactions among agents combine over time to produce harmful or beneficial system-level security outcomes. Finally, we conclude by outlining open problems for studying emergent behavior in LLM agents in the context of security. The paper is intended to provide a foundation for examining how the emerging capabilities and operational needs of LLM agents may shape security evaluations that go beyond static, model-level testing.
