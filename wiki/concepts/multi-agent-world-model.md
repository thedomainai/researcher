# マルチエージェント世界モデル

## 概要

**マルチエージェント世界モデル（Multi-Agent World Model）**とは、複数のエージェント（主体）が同時に存在するインタラクティブな環境をシミュレートするための生成モデルである。近年の映像拡散モデル（Video Diffusion Model）の発展によって、ゲームや仮想環境を動的にシミュレートする「世界モデル」の実現が進んでいるが、その多くは**単一エージェント設定**に限定されており、複数のエージェントを同時かつ独立して制御することは依然として大きな課題であった。

マルチエージェント世界モデルが重要視される理由は、現実世界やゲーム環境において複数のキャラクターやプレイヤーが独立した行動をとる場面が一般的であるためである。各エージェントの行動を正確にシーン内の対応する主体に結びつける能力（**アクションバインディング**）は、没入感の高いインタラクティブ体験の実現に不可欠な技術的要件である。

## 詳細

### アクションバインディング問題

既存の映像拡散モデルが抱える根本的な課題の一つが、**アクションバインディング（Action Binding）**の失敗である。これは、与えられた行動指示を、シーン内の複数の主体のうち「どの主体に対する指示なのか」を正しく対応付けられないという問題である。たとえば、2人のキャラクターが存在するシーンにおいて、「キャラクターAをジャンプさせる」という指示を与えた際に、誤ってキャラクターBが動いてしまうような現象が起こりうる。

### ActionParty のアプローチ

この問題に対処するために提案されたのが、**ActionParty** である。ActionParty は、生成型ビデオゲームのためのアクション制御可能なマルチ主体世界モデルであり、以下の技術的要素を核としている。

#### 主体状態トークン（Subject State Tokens）

ActionParty の中心的な概念は **主体状態トークン（Subject State Tokens）** と呼ばれる潜在変数の導入である。これらのトークンはシーン内の各主体の状態を**持続的に（persistently）**捉える役割を担う。各エージェントに対して独立した潜在表現を割り当てることで、それぞれの行動情報が混在することなく保持される。

#### 空間バイアス機構（Spatial Biasing Mechanism）

主体状態トークンと映像潜在変数（Video Latents）を**空間バイアス機構**によって共同モデリングすることで、以下の2つのプロセスを分離（disentangle）することに成功している：

- **グローバルな映像フレームレンダリング**：シーン全体の一貫した映像生成
- **個別のアクション制御による主体更新**：各エージェント固有の行動反映

この分離により、一方のエージェントの動作が他方のエージェントや背景に不要な影響を与えることなく、独立した制御が可能となる。

### 生成型ビデオゲームへの応用

ActionParty はとりわけ**生成型ビデオゲーム（Generative Video Games）**への応用を念頭に置いて設計されている。拡散モデルベースの世界モデルを用いてゲーム環境をリアルタイムにシミュレートするアプローチは、ゲームエンジンの代替や新たなインタラクティブコンテンツ生成の基盤となりうる。マルチプレイヤー環境の再現や、複数の自律エージェントが共存するシナリオのシミュレーションに対して、本手法は有効なソリューションを提供する。
