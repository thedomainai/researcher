# 身体的インタラクションを考慮した会話エージェント

## 概要

身体的インタラクションを考慮した会話エージェント（Conversational Agent with Embodied Interaction Awareness）とは、ユーザーが物理的な作業を行う際の手の動きや触覚的な操作を認識・理解し、それに応じたガイダンスや支援を提供できる対話型AIシステムのことである。

従来の会話エージェントはテキストや音声による情報交換を主体としており、ユーザーが実際に手を動かして行う「ハンズオン」作業の文脈を把握することが困難であった。しかし、手芸・修繕・工作・料理といった身体的スキルの習得においては、手の感触や操作の状態を踏まえたリアルタイムな対話的支援が不可欠である。この課題に応えるべく登場したのが、身体的インタラクション（Embodied Interaction）を認識する会話エージェントという概念である。

このアプローチは、**初心者が一人で技術的スキルを習得する際の障壁を下げる**という観点から特に重要であり、インタラクティブなチュータリング・システムの新たな方向性として注目されている。

## 詳細

### 背景と課題

手を使う作業（例：衣類の修繕、縫製など）を初心者が独学で習得しようとする場合、複数の課題が絡み合って生じる。

- **手続き的課題（Procedural Challenges）**: 作業の順序や方法を正しく理解し実行すること
- **身体的課題（Embodied Challenges）**: 素材の感触、道具の扱い、力加減といった感覚的・運動的側面

既存のデジタルツール（動画チュートリアル、FAQシステム、一般的なチャットボットなど）は、これらの課題に対して包括的なサポートを提供できていない。特に、ユーザーがテキスタイル（布・糸など）と実際にインタラクションしている状態を認識する機能を欠いている点が大きな問題とされている。

### RepairBotフレームワーク

**RepairBot**は、衣類修繕という具体的なドメインを対象として開発された「Human-Touch-Aware（人間の触覚を認識する）」会話エージェントである（Liu et al., 2026）。その設計は以下の多段階研究プロセスに基づいている。

#### 1. オートエスノグラフィーによる初心者体験の把握

研究の出発点として、研究者自身が初心者として衣類修繕を経験するオートエスノグラフィー（Autoethnography）を実施した。これにより、初心者が実際にどのような困難に直面するかを内側から理解し、エージェント設計に必要な洞察を得た。

#### 2. RepairBot会話フレームワーク（RBCF）の開発

オートエスノグラフィーの知見をもとに、**RepairBot Conversation Framework（RBCF）** が構築された。このフレームワークは、作業の進捗状況、つまずきのパターン、ユーザーの触覚的インタラクションの状態を考慮した対話設計を提供する。

#### 3. テクノロジープローブとウィザード・オブ・オズ手法

RBCFを実装した**テクノロジープローブ（Technology Probe）**（プロトタイプシステム）を開発し、**ウィザード・オブ・オズ（Wizard-of-Oz）手法**を用いてHuman-Touch-Awarenessをシミュレートした。

- ウィザード・オブ・オズ手法では、AIによる自動認識の代わりに、裏側で人間の研究者がリアルタイムに操作・応答することで、将来的な自動化技術が実現した場合のユーザー体験を先行的に評価する。

#### 4. 研究の成果

このプロトタイプを用いた実験によって、身体的インタラクションを認識する会話エージェントが以下の点で有効であることが示された：

- **修繕スキルの学習支援**: 初心者が手順を理解し、実践するプロセスへの効果的なガイダンス
- **衣類への愛着形成**: ユーザーが自分自身の衣服と向き合い、物への関与（エンゲージメント）を高めること

### ユーザーの主体感（Sense of Agency）との関係

身体的インタラクションを考慮したシステムを設計する際には、ユーザーの**主体感（Sense of Agency）**、すなわち「自分が作業を制御・主導している」という感覚を損なわないことが重要な設計課題となる。

Jobert et al.（2026）による**Swarm UIs**に関する研究では、AIによるアシスタンスの程度がユーザーの主体感に与える影響が検討されている。支援が過剰になると、ユーザーは自分が作業の「主体」ではなく「受動的な操作者」であると感じるリスクがある。身体的インタラクションを認識するエージェントの設計においては、このトレードオフを適切にバランスさせることが求められる。

### 設計上の重要な原則

これらの研究から導出される設計原則を以下に整理する。

| 原則 | 説明 |
|------|------|
| **コンテキスト認識** | ユーザーの物理的な作業状態をリアルタイムで把握する |
| **段階的支援** | 初心者の習熟度に合わせて支援の粒度を調整する |
| **主体感の保持** | ユーザーが自律的に意思決定できる余地を残す |
| **身体性の包摂** | 触覚・動作といた非言語的情報を対話設計に統合する |
| **ホリスティックサポート** | 手順的知識と身体的スキルの両方をカバーする |
