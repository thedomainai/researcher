# 実装アウトカム

**実装アウトカム（Implementation Outcomes）**とは、科学的根拠に基づいた介入（Evidence-Based Interventions: EBIs）や新たな治療法、プログラムなどを実社会の現場に導入・定着させるプロセスにおいて、その「実装の成功度」を評価するための指標群である。

実装科学（Implementation Science）における中心的な概念であり、治療そのものの効果を示す「臨床アウトカム」や、支援体制の質を示す「サービスシステムアウトカム」とは明確に区別される。

## 概要

新たな介入策がどれほど臨床的に優れていても、現場のスタッフに受け入れられず、正しく実行されなければ、患者や利用者にその恩恵は届かない。実装アウトカムは、**「介入そのものが有効だったのか（介入の効果）」**と**「介入が適切に現場に導入されたのか（実装の効果）」**を切り分けて評価するために不可欠な概念である。

実装アウトカムを明確に定義し、測定可能にすることで、実装プロセスのどこに課題があるのかを特定し、効果的な実装戦略の立案や評価を行うことが可能になる。

## 実装アウトカムの分類と定義

プロクター（Enola K. Proctor）らの研究（2010年）は、実装アウトカムを以下の8つの概念に分類するタクソノミ（分類体系）を提唱している。

| アウトカム | 定義 |
| :--- | :--- |
| **受容性 (Acceptability)** | 実施に関わる人々（実務者や組織）が、その介入を「好ましい」「満足できる」と認識している度合い。 |
| **採択 (Adoption)** | 介入を自らの組織や実践に「取り入れよう」「開始しよう」とする意向、初期の決定、または行動。 |
| **適切性 (Appropriateness)** | 特定の現場、問題、あるいは対象読者にとって、その介入が「適合している」「適切である」と認識されている度合い（受容性と類似するが、客観的な適合性に焦点を当てる）。 |
| **実現可能性 (Feasibility)** | 特定の組織や文脈において、その介入を実際に「実行・実施できる」度合い。 |
| **忠実度 (Fidelity)** | 介入が、開発者の意図や本来のプロトコル通りに「正確に実施されている」度合い。 |
| **実装コスト (Implementation Cost)** | 実装プロセスそのもの（研修、コンサルテーション、システム変更など）に要する費用。 |
| **浸透度 (Penetration)** | 組織内の対象となるすべての部門やスタッフのうち、実際にその介入を実践・適用している割合。 |
| **持続可能性 (Sustainability)** | 初期の実装支援やプロジェクト期間が終了した後も、その介入が組織内で「維持・継続される」度合い。 |

### 測定手法の開発と心理計量的評価
これらのアウトカムを正確に測定するため、ワイナー（Bryan J. Weiner）ら（2017年）の研究により、特に概念的な重複が起こりやすい「受容性」「適切性」「実現可能性」の3つについて、信頼性と妥当性を備えた以下の新しい尺度（各4項目）が開発された。

1. **AIM (Acceptability of Intervention Measure)**: 介入の受容性を測定
2. **IAM (Intervention Appropriateness Measure)**: 介入の適切性を測定
3. **FIM (Feasibility of Intervention Measure)**: 介入の実現可能性を測定

心理計量的評価により、これら3つの尺度は高い弁別妥当性（異なる概念を混同せずに測定できていること）と信頼性を持つことが実証されている。
