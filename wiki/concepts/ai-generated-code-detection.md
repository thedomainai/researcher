# AI生成コード検出

## 概要

AI生成コード検出（AI-Generated Code Detection）とは、大規模言語モデル（LLM）やコード生成AIツールによって自動生成されたソースコードを、人間が記述したコードと区別するための技術・手法の総称である。

近年、GitHub Copilot や ChatGPT をはじめとするAIコード生成ツールの急速な普及により、ソフトウェア開発の自動化が大きく進展している。しかしその一方で、AI生成コードの増加は以下のような多面的なリスクをもたらすとして注目されている。

- **コード品質の低下**: AIが生成するコードは、微妙なバグや非効率な実装を含む場合がある
- **セキュリティ上の脆弱性**: 既知の脆弱なパターンを再現してしまうリスク
- **知的財産の問題**: 学習データに含まれるコードの著作権侵害の可能性
- **学術的誠実性の毀損**: 教育・評価場面における不正利用

これらの問題に対処するため、AI生成コードを自動的に識別する検出技術の研究が急務となっている。

---

## 詳細

### 既存手法の課題

AI生成コード検出に関する既存研究の多くは、以下のような限界を抱えていた。

1. **単一モデルへの依存**: 単一の事前学習済みモデルのみを使用するアプローチが主流であり、コードの多次元的な特徴を十分に捉えられない
2. **均質な特徴抽出**: 意味論（セマンティクス）と構文（シンタックス）の両方を統合的に学習する仕組みが不足している
3. **プログラミング言語の偏り**: Python や Java などの主要言語への集中が顕著であり、Go 言語のようなシステム系言語への対応が手薄であった

### デュアルエンコーダによるアプローチ

Liao ら（2026）は、Go 言語を対象とした **デュアルエンコーダ型 AI生成コード検出器** を提案している。本手法の主要な特徴は以下のとおりである。

#### デュアルエンコーダ特徴融合フレームワーク

2つの異なるコード向け事前学習モデルを組み合わせることで、補完的な特徴を抽出する設計を採用している。

| エンコーダ | 役割 |
|---|---|
| **CodeBERT** | コードとテキストのバイモーダル表現学習に強み。意味的特徴の抽出に寄与 |
| **UniXcoder** | 統一されたクロスモーダルな事前学習。構文的・構造的特徴の抽出に寄与 |

この2つのエンコーダの出力を融合することで、意味論と構文論の両軸から AI生成コードの特徴を多次元的に捉えることを目指している。

#### Go 言語への特化

Go 言語は、並行処理の記述スタイルや独自の型システムなど、他の言語とは異なる構文・セマンティクス上の特徴を持つ。本手法はこの特性に対応した検出を実現する点で、既存研究との差別化を図っている。

### 技術的背景：なぜ多次元特徴融合が有効か

AIが生成するコードは、人間のコードと比較して以下のような統計的・構造的特徴を持つことが知られている。

- **語彙・スタイルの均質性**: 特定のトークン頻度パターンや命名規則への偏り
- **抽象構文木（AST）の構造的差異**: 制御フローや関数呼び出しの分布が異なる
- **コメントと実装の関係性**: 自然言語的な説明と実装の対応パターンの違い

単一のエンコーダでは、これらの特徴のうち一側面しか捉えられないが、デュアルエンコーダはセマンティクスと構文の両面から特徴を抽出・融合することで、検出精度の向上を狙う。
