# 神経言語学的形態統語処理と言語変化

## 概要

**神経言語学的形態統語処理と言語変化**とは、言語の文法的微変異（microvariation）や進行中の言語変化が、話者の脳内における文処理プロセスにどのような神経生理学的・行動的影響を与えるかを探求する研究領域である。

この分野では、方言間・話者間で生じる形態統語的変異（例：格変化、一致マーキングなど）を、事象関連電位（ERP）などの神経科学的手法を用いて計測・分析することで、言語変化が個人の言語処理システムにどのように内在化されるかを明らかにしようとする。

この研究領域が重要である理由は以下の点にある。

- **言語変化の神経基盤の解明**: 言語が変化する過程において、話者の脳がどのように文法的ゆらぎを処理・適応するかを直接観察できる。
- **個人差と言語変異の関係**: 話者個人の言語産出パターンが、文処理の神経シグネチャと体系的に関連していることを示す可能性がある。
- **理論的・応用的意義**: 形態統語論、神経言語学、方言学、歴史言語学を横断する橋渡し的な知見を提供する。

## 詳細

### 研究背景：ノルウェー語分詞一致の微変異

Sandstedt et al.（2026）は、ノルウェー語の**分詞一致（participial agreement）**に焦点を当てた。ノルウェー語では、分詞の一致マーキングが方言間・話者間で広範かつほぼ連続的な変異を示しており、現在進行中の形態統語的変化の「生きた実験場」として機能している。

この変異は、単なる方言差にとどまらず、同一話者内（イントラスピーカー変異）でも観察されるため、言語変化の初期段階における処理メカニズムを調べるうえで特異な研究文脈を提供している。

### 研究デザインと手法

| 項目 | 内容 |
|------|------|
| **参加者数** | 156名 |
| **方言地域** | 2つの方言地域（inter-/intra-speaker変異が豊富な地域） |
| **使用言語** | 標準化されたノルウェー語ブークモール（Bokmål） |
| **刺激** | 不変形（統制条件）または変異・変化中の文法形式（ターゲット条件）を含む文 |
| **計測手法** | 事象関連電位（Event-Related Potentials: ERP） |
| **主な変数** | 個人の言語産出パターン（産出変異性）と文処理中の神経反応 |

#### ERPとは

事象関連電位（ERP）は、特定の認知・言語刺激に対して脳が生成する電気的応答を時間的に高精度で計測する手法である。形態統語処理の研究では、**LAN（Left Anterior Negativity）**や**P600**などの成分が、文法違反や予測外の統語構造への反応として知られている。

### 主要な知見

1. **個人の産出変異性が神経処理差を予測する**
   - 話者が日常的に変異形をどの程度産出するかという個人差が、ERP反応の差異と体系的に対応していることが示唆される。すなわち、より多く変異形を産出する話者は、変異・変化中の文法形式に対して異なる神経シグネチャを示す。

2. **文法的微変異の広範な影響**
   - 方言間の広域な変異（マクロ変異）だけでなく、話者内の細かなゆらぎ（マイクロ変異）が、オンライン文処理に独自の影響を及ぼすことが確認された。

3. **進行中の言語変化と処理の連続性**
   - 言語変化は一様に起きるのではなく、個人の産出行動と認知処理の間で段階的・連続的に内在化されていくことが示唆される。

4. **標準語処理における方言背景の影響**
   - 参加者は標準化されたブークモールで書かれた文を読んだにもかかわらず、出身方言の背景が処理パターンに影響を与えており、方言経験が標準語処理に転移することを示している。

### 理論的含意

この研究は、**言語処理は静的な文法知識のみに基づくのではなく、話者が日常的に経験する産出変異の確率的パターンに動的に適応している**という仮説を支持する。これは[[確率論的言語処理モデル]]や[[語彙アクセスと形態論]]の議論とも接続する重要な知見である。

また、言語変化の研究において、社会言語学的・コーパス的手法に加えて神経科学的手法を組み合わせることで、変化のメカニズムを個人レベルで追跡できる可能性が開かれた。
