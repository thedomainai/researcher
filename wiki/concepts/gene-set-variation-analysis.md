# 遺伝子セット変動解析（GSVA）

**遺伝子セット変動解析（Gene Set Variation Analysis: GSVA）**は、マイクロアレイやRNA-Seq（RNAシーケンシング）などの遺伝子発現プロファイルデータから、サンプルごとにパスウェイ（遺伝子セット）の活性化レベルを評価するための強力なバイオインフォマティクス手法です。

従来の遺伝子セットエンリッチメント解析（GSE解析）が「症例群 vs 対照群」といった単純な2群間比較を前提としていたのに対し、GSVAは**完全なノンスーパーバイズド（教師なし）**なアプローチを採用しており、サンプルの臨床情報やラベルを事前に必要とせずに、集団内における各サンプルのパスウェイ活性の変動を推定できる点に大きな特徴があります。

---

## 概要

遺伝子発現データ（トランスクリプトームデータ）の解析において、個々の遺伝子を個別に評価するシングルジーン解析は、測定ノイズの影響を受けやすく、また得られる結果の生物学的な解釈が難しいという課題があります。

これに対し、関連する遺伝子の集まりである「遺伝子セット（パスウェイなど）」を単位として解析する遺伝子セットエンリッチメント（GSE）アプローチは、以下のメリットを提供します：
- **ノイズの低減**：複数の遺伝子情報を統合することで測定誤差の影響を抑える。
- **次元削減**：数万の遺伝子データを、数百〜数千のパスウェイデータに圧縮する。
- **生物学的解釈の容易化**：生物学的な機能や代謝経路に直接関連付けた評価が可能になる。

分子プロファイリング実験が、単純な2群比較から、時間経過、治療応答、多様な臨床サブタイプを持つ「高度に不均一（ヘテロ）なデータセット」へと移行するにつれ、サンプル単位で堅牢かつ柔軟にパスウェイ活性をモデル化できる手法としてGSVAが開発されました。

---

## 詳細な特徴と知見

2013年にSonja Hänzelmann、Robert Castelo、Justin Guinneyらによって発表されたGSVAは、マイクロアレイおよびRNA-Seqデータの両方に適用可能なサンプル単位（sample-wise）のエンリッチメント解析手法です。

### 1. サンプル単位のエンリッチメントスコア算出
従来のGSA（Gene Set Analysis）手法の多くは、サンプル群全体の差異に基づいて遺伝子セットの豊富さをスコア化します。しかし、GSVAは各サンプル内の遺伝子発現順位に基づき、サンプルごとに独立したエンリッチメントスコア（GSVAスコア）を算出します。これにより、遺伝子発現行列（遺伝子×サンプル）を、パスウェイ活性行列（パスウェイ×サンプル）へと直接変換することができます。

### 2. 教師なし学習（Unsupervised）によるアプローチ
サンプルの表現型（表現型ラベルや疾患ステージなど）の情報を一切使用せずに計算を行います。これにより、以下のような高度で不均一なデータセットに対しても頑健に対応可能です。
- がんの不均一性（ヘテロジェネティス）の評価
- 臨床サブクラスの特定
- 時間変化に伴う動的なパスウェイ活性の追跡

### 3. 高い堅牢性（Robustness）
開発者らによる他の標準的なサンプル単位エンリッチメント手法（ssGSEAなど）との比較評価において、GSVAはノイズに対する高い耐性と、異なるプラットフォーム（マイクロアレイとRNA-Seqなど）間での一貫したシグナル検出性能を示し、優れた頑健性が実証されています。
