# 計算論的合理性に基づくユーザーモデリング

## 概要

**計算論的合理性に基づくユーザーモデリング（Computational-Rational User Modeling, CR User Modeling）**とは、認知的制約を持つ人間ユーザーの行動を、「非合理」として単純に棄却するのではなく、**認知的境界（cognitive bounds）とバイアスのかかった信念のもとで最適な意思決定を行う合理的エージェント**として形式的にモデル化するアプローチである。

AIシステムや対話型エージェントがユーザーと協調する場面では、ユーザーの最適でない行動（sub-optimal behavior）を予測・推論することが不可欠である。従来の研究では、このような行動はしばしば「非合理性」の産物として扱われてきたが、CR ユーザーモデリングはその前提を覆し、**認知的制約と偏った世界観に起因する合理的判断**として再解釈する点に本質的な新規性がある。

---

## 詳細

### 背景と動機

AIおよびそれを基盤とする技術の急速な発展にもかかわらず、ユーザーや人間コラボレーターの最適でない行動を正確に予測・推論することは依然として困難な課題である。多くの場合、こうした行動は「非合理性」に由来するのではなく、以下の要因に基づく合理的な意思決定の結果である：

- **内在的な認知的制約（cognitive bounds）**：人間が処理できる情報量や記憶容量には限界がある
- **世界についてのバイアスのかかった信念（biased beliefs）**：過去の経験や記憶の制限により、主観的な世界モデルが歪む

### CR ユーザーモデルの形式的定義

Zhu らは、**認知的制約下で偏った信念のもと最適に行動するエージェントのクラス**として、CR ユーザーモデルを形式的に定義した。このモデルの中心的な特徴は以下の通りである：

#### 1. 有界記憶プロセス（Bounded Memory Process）
モデルの核心的な新規性は、**有界な記憶プロセスがどのように動的に非一貫（dynamically inconsistent）でバイアスのかかった信念状態を引き起こすか**を明示的にモデル化した点にある。ユーザーは完全な履歴を保持できず、過去の観測に基づく信念が歪む結果として、逐次的意思決定において最適でない行動を取る。

#### 2. 動的に非一貫な信念状態
有界記憶に起因する信念の歪みは、時間軸を跨いだ意思決定の一貫性を損なう。これにより、同一ユーザーが異なる時点で矛盾した選択をする現象を自然に説明できる。

#### 3. パラメータ化された認知プロセス
CR モデルは、**明示的かつパラメータ化された認知プロセス**を持つため、以下の推論が実行可能（tractable）になる：
- **潜在的なユーザー固有の認知的制約の同定**：各ユーザーの記憶上限などの個人差を推定する
- **バイアスのかかった信念状態のオンライン推論**：受動的な観測データのみから、リアルタイムにユーザーの信念状態を推定する

### 解決する課題

本研究が正面から取り組む課題は以下の二点である：

| 課題 | 説明 |
|------|------|
| 潜在的な認知的制約の同定 | ユーザーごとに異なる記憶容量などの上限を、観測から特定する |
| バイアスのある信念状態の推論 | 受動的な行動観測のみから、ユーザーの主観的信念をオンラインで継続推定する |

これらの課題は、明示的・パラメータ化された認知プロセスを持つ CR モデルファミリーにより、**計算的に扱いやすい問題（tractable）として定式化できる**とされている。

### 従来手法との比較

| 観点 | 従来アプローチ | CR ユーザーモデリング |
|------|--------------|---------------------|
| 最適でない行動の解釈 | 非合理性として扱う | 制約下での合理的判断として扱う |
| 信念のモデル化 | 静的・均一 | 動的・個人固有・バイアスあり |
| 認知プロセスの表現 | 暗黙的 | 明示的かつパラメータ化 |
| オンライン推論 | 困難 | 扱いやすい |
