# 計算合理的ユーザーモデリング

## 概要

**計算合理的ユーザーモデリング（Computational-Rational User Modeling, CR User Modeling）**とは、人間の認知的制約や偏った信念（biased beliefs）を明示的にモデル化することで、ユーザーや人間の協力者の**準最適な行動（sub-optimal behavior）**を予測・推定するための計算論的枠組みである。

従来のアプローチでは、人間の非合理的に見える行動を単純に「不合理（irrational）」として扱うことが多かった。しかし計算合理的ユーザーモデリングは、そのような行動の多くが**認知的制約（cognitive bounds）と世界に対する偏った信念のもとで下された合理的な意思決定**の結果であるという視点に立つ。つまり、ユーザーは「不合理なエージェント」ではなく、「制約のある合理的エージェント（bounded rational agent）」として定式化される。

AIシステムが人間と協調する場面が増える中、ユーザーの行動を正確にモデル化する能力はAIの有用性・安全性・信頼性に直結するため、本分野の重要性は急速に高まっている。

---

## 詳細

### 背景と動機

AIおよびそれを基盤とする技術の急速な発展にもかかわらず、ユーザーや人間の協力者の**準最適な行動を予測・推定すること**は依然として重大な課題である。多くの場合、こうした行動は単なる不合理性に起因するのではなく、以下の要因によって引き起こされる：

- **固有の認知的制約（inherent cognitive bounds）**：記憶容量や処理能力などの認知リソースの限界
- **世界に対する偏った信念（biased beliefs about the world）**：不完全な情報や記憶の歪みから生じる認識のバイアス

この視点は、「人間は一貫して非合理だ」という単純な仮定を退け、より精緻な人間行動モデルを要求する。

---

### 計算合理的（CR）ユーザーモデルの定式化

Zhuら（2026）は、**認知的制約のもとで偏った信念に従って最適に行動するエージェント**のクラスを計算合理的（CR）ユーザーモデルとして正式に定義した。このモデルファミリーの核心的な新規性は以下の点にある：

1. **有界記憶プロセス（bounded memory process）のモデル化**  
   記憶の限界が動的に一貫性を欠く（dynamically inconsistent）バイアスのかかった信念状態を生み出すメカニズムを明示的に記述する。

2. **準最適な逐次意思決定への接続**  
   上記の偏った信念状態が、結果として準最適な逐次意思決定（sub-optimal sequential decision-making）にどのように繋がるかを形式化する。

3. **明示的・パラメータ化された認知プロセス**  
   認知プロセスを明示的かつパラメータ化された形で組み込むことで、モデルの解釈可能性と推定の扱いやすさ（tractability）を確保する。

---

### 主要な技術的課題と解決策

CRユーザーモデリングにおける中心的な技術的挑戦は以下の2点である：

| 課題 | 説明 |
|------|------|
| **潜在的ユーザー固有の制約の同定** | 各ユーザーに固有の認知的制約（latent user-specific bound）を観測データから推定すること |
| **偏った信念状態のオンライン推論** | 受動的な観測（passive observations）のみからリアルタイムで偏った信念状態を推定すること |

Zhuらは、明示的かつパラメータ化された認知プロセスを持つCRモデルファミリーにおいて、これらの課題が**扱いやすい（tractable）**形で解決可能であることを示した。これはモデルの実用的な展開可能性を示す重要な理論的保証である。

---

### 行動経済学・HCIとの接点

本アプローチは**行動経済学（behavioral economics）**の知見、特に**限定合理性（bounded rationality）**の概念と深く結びついている。計算合理的ユーザーモデリングはこれを計算論的に具体化し、AIシステムへの組み込みを可能にする橋渡しを果たす。応用領域として以下が挙げられる：

- **インテリジェントUI・推薦システム**：ユーザーの誤った信念を考慮したインタフェース設計
- **人間-AIコラボレーション**：AIエージェントが人間の認知状態を推定しながら協調行動を取る
- **教育・支援システム**：学習者の知識の偏りや誤解をモデル化した適応型支援
