# 計算論的合理性に基づくユーザーモデリング

## 概要

**計算論的合理性に基づくユーザーモデリング（Computational-Rational User Modeling, CR User Modeling）**とは、認知的制約（cognitive bounds）を持つ人間が、偏ったビリーフ（信念）のもとで合理的に行動するという前提に立ち、そのユーザーの意思決定プロセスを形式的にモデル化するアプローチである。

AIシステムや人間とのコラボレーションツールの急速な普及に伴い、ユーザーの「最適ではない行動（sub-optimal behavior）」を予測・推論することが重要な課題となっている。従来のアプローチでは、こうした行動を単純に「非合理（irrational）」として扱う傾向があったが、計算論的合理性の観点では、**そのような行動は非合理の結果ではなく、認知的な制約と世界に対する偏ったビリーフのもとでの合理的な意思決定の結果**として捉え直される。この視点の転換が、より精密でより人間的なユーザーモデルの構築を可能にする。

---

## 詳細

### 背景と動機

AIおよびそれを基盤とする技術の爆発的な成長にもかかわらず、ユーザーや人間の協力者が示す最適でない行動を予測・推論することは依然として重大な課題である。従来の行動経済学的アプローチや機械学習ベースのユーザーモデルでは、観測された行動のずれを「ノイズ」または「非合理性」として扱うことが多かった。

しかし Zhu らの研究（2026）は、こうした行動のずれの多くが、以下の2つの要因によって説明できると主張する：

1. **認知的制約（Cognitive Bounds）**: 人間の記憶や処理能力は本質的に有限である。
2. **偏ったビリーフ（Biased Beliefs）**: 上記の認知的制約により、世界の状態に対する信念が歪む。

### CR ユーザーモデルの形式的定義

本研究では、認知的制約のもとで**偏ったビリーフに基づいて最適に行動する**エージェントのクラスとして、**計算論的合理性（Computational-Rational, CR）ユーザーモデル**を正式に導入する。

このモデルファミリーの核心的な新規性は以下の点にある：

- **有界な記憶プロセス（Bounded Memory Process）のモデル化**: 記憶の制約がどのようにして、時間的に非一貫（dynamically inconsistent）かつ偏ったビリーフ状態を動的に生じさせるかを明示的にモデル化する。
- **逐次的意思決定への影響**: 偏ったビリーフ状態が、結果として最適でない逐次的意思決定にどうつながるかを体系的に記述する。

### 推論の課題と解決可能性

CR ユーザーモデルの実用化における主要な課題は次の2つである：

| 課題 | 説明 |
|---|---|
| **潜在的なユーザー固有の制約の特定** | 各ユーザーの認知的制約のパラメータは観測不可能（latent）であり、個人差も大きい。 |
| **偏ったビリーフ状態のリアルタイム推論** | 受動的な観測（passive observations）から、オンザフライでビリーフの歪みを推定する必要がある。 |

Zhu らはこれらの課題に対し、**明示的かつパラメータ化された認知プロセス**を持つ CR モデルファミリーを用いることで、この推論問題が**tractable（扱いやすい）**になると主張する。すなわち、認知プロセスを明示的に定式化することで、潜在変数の推定が計算上実行可能な問題となる。

### 従来の「非合理モデル」との違い

| 観点 | 従来の非合理モデル | CR ユーザーモデル |
|---|---|---|
| 行動のずれの解釈 | ノイズ・非合理性 | 制約下での合理的選択 |
| 認知的制約の扱い | 暗黙的・無視 | 明示的・パラメータ化 |
| ビリーフのモデル化 | 静的または理想的 | 動的・偏りを含む |
| 推論の対象 | 観測された行動のみ | 潜在的な認知状態 |
