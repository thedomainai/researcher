# ビジネスプロセス・リエンジニアリング（ITによる業務再設計）

**ビジネスプロセス・リエンジニアリング（BPR: Business Process Redesign / Reengineering）**とは、情報技術（IT）のケイパビリティを最大限に活用し、組織の業務プロセスを根本から再設計・変革するマネジメント手法です。

1990年にトーマス・H・ダベンポート（Thomas H. Davenport）とジェームズ・E・ショート（James E. Short）によって提唱されたこの概念は、それまでの「既存の業務プロセスを単に自動化・効率化する」というIT投資のあり方を覆し、「ITを前提として、プロセスそのものをゼロベースで再構築する」という新しいオペレーション管理のアプローチを提示しました。

---

## 概要

従来の産業工学（Industrial Engineering）が時間・動作研究を通じて物理的な作業の効率化を目指したのに対し、ダベンポートらは情報技術（IT）を「新しい産業工学（The New Industrial Engineering）」の核として位置づけました。

組織が劇的な業績向上（コスト削減、時間短縮、品質向上など）を達成するためには、個別のタスクの最適化ではなく、**顧客に価値を提供する一連の活動である「ビジネスプロセス」全体をITによって再設計すること**が不可欠であるとされています。ITは単なる業務の「支援ツール」ではなく、新しい業務プロセスのあり方を定義する「イネーブラー（実現要因）」として機能します。

---

## 詳細セクション：ITによる業務再設計のフレームワーク

ダベンポートとショートが示したフレームワークでは、ITとビジネスプロセスは互いに依存し合う関係（双方向の関係）にあります。すなわち、「ビジネスプロセスをどのように変革すべきか」という問いと、「ITによってどのようなプロセスが実現可能になるか」という問いを同時に考える必要があります。

### 1. 業務再設計（BPR）の5つのステップ

1. **ビジネスビジョンとプロセス目的の策定**
   - コスト削減、時間短縮、品質向上、あるいは従業員の学習・エンパワーメントなど、再設計の明確な目的（ビジョン）を定義する。
2. **再設計対象となるプロセスの特定**
   - 組織内のすべてのプロセスを同時に変革することは不可能です。ビジネスへの影響度、ボトルネックの存在、再設計の実現可能性などを基準に、優先度の高いプロセスを特定する。
3. **既存プロセスの理解と測定**
   - 現在のプロセスにおける問題点や基準値（コスト、時間など）を測定し、再設計後の効果を比較できるようにする。ただし、現状分析に時間をかけすぎない（分析麻痺に陥らない）ことが重要。
4. **ITイネーブラー（ITケイパビリティ）の特定**
   - プロセスを劇的に変革できるITの技術的特性（データベース、通信ネットワーク、意思決定支援システムなど）を特定する。
5. **プロセスのプロトタイプ構築と設計**
   - 特定されたITケイパビリティを組み込み、新しい業務プロセスのプロトタイプを構築・テストし、組織へ実装する。

### 2. ITがプロセスに変革をもたらす「9つのケイパビリティ」

ITが業務プロセスを再設計する際、具体的にどのような価値（イネーブラーとしての機能）を提供するのか、以下のように整理されています。

| ITの特性（ケイパビリティ） | ビジネスプロセスへの影響・効果 |
| :--- | :--- |
| **トランザクション機能 (Transactional)** | 構造化されたプロセスをルール化し、自動化する。 |
| **地理的機能 (Geographical)** | 距離の制約をなくし、離れた場所での共同作業や調整を可能にする。 |
| **自動化機能 (Automational)** | プロセスから人間の労働を排除、または削減する。 |
| **分析機能 (Analytical)** | 高度な分析ツールをプロセスに組み込み、複雑な意思決定を支援する。 |
| **情報共有機能 (Informational)** | 膨大な情報をプロセス全体に流通させ、業務状況を可視化する。 |
| **シーケンス機能 (Sequential)** | 並行処理を可能にし、プロセス全体のリードタイムを短縮する。 |
| **追跡・管理機能 (Tracking)** | プロセスの実行状態や成果物の移動をリアルタイムに追跡する。 |
| **知識管理機能 (Knowledge Management)** | 専門知識やノウハウを体系化し、必要なプロセスに統合する。 |
| **組織間連携機能 (Disintermediation)** | 仲介者を排除し、サプライチェーンなど組織間のプロセスを直接接続する。 |
