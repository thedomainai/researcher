# ポストCOVID神経認知機能障害と自己免疫

## 概要

ポストCOVID神経認知機能障害（Post-COVID Neurocognitive Dysfunction）とは、SARS-CoV-2感染後に持続する認知機能の低下を主症状とする「ポストCOVID-19症候群（PCS）」の一側面である。倦怠感・集中力低下・語想起困難（word-finding difficulties）などの症状が長期にわたって続くことが特徴であり、世界中で多数の患者に影響を与えている。

この領域における重要な研究課題の一つが、**自己免疫メカニズムの関与**である。感染後に誘導された自己抗体が神経系を標的とし、認知・運動機能に障害をもたらす可能性が示唆されており、治療戦略の開発においても大きな意義を持つ。なかでも、興奮性神経伝達物質であるグルタミン酸の小胞型トランスポーター（VGLUT2）に対する自己抗体（抗VGLUT2自己抗体）の発見は、この分野における新たな知見として注目されている。

---

## 詳細

### 抗VGLUT2自己抗体の発見

2026年にJames らが報告した症例研究は、ポストCOVID神経認知機能障害と自己免疫の関連を示す先駆的な事例である。対象は44歳の男性で、SARS-CoV-2感染後に以下の持続症状を呈した。

- **重篤な認知的・運動的疲労**
- **語想起困難**（言葉が出てこない）
- **集中力の著しい低下**

#### 神経心理学的評価

神経心理学的検査により、以下の機能領域における顕著な障害が確認された。

| 評価領域 | 所見 |
|---|---|
| 覚醒度（alertness） | 著明な低下 |
| 注意機能（attention） | 著明な低下 |
| 流暢性（fluency） | 著明な低下 |
| 処理速度（processing speed） | 著明な低下 |

#### 血清学的所見

血清解析の結果、**抗VGLUT2自己抗体（anti-VGLUT2 autoantibodies）**が検出された。VGLUT2（小胞型グルタミン酸トランスポーター2）は、グルタミン酸作動性シナプスにおいてグルタミン酸を小胞に充填する輸送体タンパク質であり、興奮性神経伝達において中心的な役割を担う。このタンパク質に対する自己抗体の産生は、神経伝達の機能不全を招き、認知・運動症状につながりうると考えられる。

### 治療介入と転帰

本症例では、**静注免疫グロブリン（IVIG）療法**が試みられた。結果として、患者本人の主観的な症状改善は認められたものの、客観的な神経心理学的指標における改善は確認されなかった。この乖離は、PCS患者における自覚症状と客観的評価の解離という、より広い臨床的課題を反映している可能性がある。

### 病態生理学的仮説

本報告はポストCOVID症候群において抗VGLUT2自己抗体が検出された**世界初の症例**とされており、以下の病態生理学的仮説を提起している。

1. **SARS-CoV-2感染が自己免疫を誘発**し、神経系のタンパク質（VGLUT2）を標的とする自己抗体が産生される。
2. 抗VGLUT2抗体がグルタミン酸作動性神経伝達を障害し、**認知・疲労症状の一因**となる。
3. この機序はポストCOVID神経認知機能障害の一つのサブタイプを形成する可能性がある。

ただし、著者らは「この仮説の確認にはより大規模なコホートでの研究が必要である」と強調しており、本症例は出発点に過ぎない。

### 研究上の意義と限界

| 項目 | 内容 |
|---|---|
| **意義** | PCSにおける自己免疫性神経障害の新たなバイオマーカー候補の提示 |
| **意義** | 治療ターゲットとしてのVGLUT2経路の可能性を示唆 |
| **限界** | 単一症例報告であり、因果関係の確立には不十分 |
| **限界** | IVIG療法の客観的効果が示されなかった |
| **限界** | 抗体の病原性（pathogenicity）の直接的証明がない |
