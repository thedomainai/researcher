# マルチエージェントシステムにおける信頼・セキュリティ

## 概要

マルチエージェントシステム（Multi-Agent Systems; MAS）における信頼・セキュリティとは、複数の自律的なAIエージェントが協調・委任・通信を行う環境において、各エージェントの行動の正当性を保証し、悪意ある操作や意図の逸脱を防ぐための理論的・実践的枠組みを指す。

現代のAIシステムでは、エージェントAがエージェントBに処理を委任し、BがツールCをユーザーXの代理として呼び出すといった複雑な委任連鎖（Delegation Chain）が常態化している。このような環境では、「どの認可チェーンがこの行動につながったのか」「どの時点でポリシーが違反されたのか」を追跡・検証することが従来の枠組みでは困難であった。

また、セキュリティの技術的側面にとどまらず、エージェント同士が「信頼」をいかに構築・維持するかという社会的・倫理的次元も重要な研究課題となっている。特に、責任ある行動と信頼形成のメカニズムを設計することは、オープンなマルチエージェント環境における根本的な挑戦である。

## 詳細

### 1. 委任連鎖のセキュリティ：SentinelAgent

#### 1.1 問題の背景

連合型（Federal）マルチエージェントAIシステムでは、エージェント間の委任関係が多層にわたって形成される。既存のフレームワークは、こうした委任連鎖全体を通じた認可の追跡やポリシー違反の特定に対応できていない。

#### 1.2 委任連鎖計算（Delegation Chain Calculus; DCC）

Patil（2026）が提案する **SentinelAgent** は、検証可能な委任連鎖を実現するための形式的フレームワークである。その中核となる **委任連鎖計算（DCC）** は、委任連鎖が満たすべき7つの性質を定義する。

| 性質 | 種別 | 内容 |
|------|------|------|
| 権限の縮小（Authority Narrowing） | 決定論的 | 委任のたびに権限が縮小・制限される |
| ポリシー保存（Policy Preservation） | 決定論的 | 委任を経てもポリシーが維持される |
| 鑑識的再構成可能性（Forensic Reconstructibility） | 決定論的 | 行動の経緯を事後的に再構成できる |
| カスケード封じ込め（Cascade Containment） | 決定論的 | 障害や違反が連鎖的に拡大しない |
| スコープ・アクション適合性（Scope-Action Conformance） | 決定論的 | 行動がスコープに適合している |
| 出力スキーマ適合性（Output Schema Conformance） | 決定論的 | 出力形式がスキーマに従っている |
| 意図保存（Intent Preservation） | 確率論的 | 委任連鎖を通じて元の意図が保持される |

さらに4つのメタ定理と1つの命題が定式化されており、特に**決定論的な意図検証の実践的不可能性**が証明されている点が理論上の重要な知見である。

#### 1.3 意図保存委任プロトコル（IPDP）

DCCに基づく **Intent-Preserving Delegation Protocol（IPDP）** は、非LLMベースの **Delegation Authority Service** を通じて、上記7つの性質をランタイムで強制する。

- **3段階検証ライフサイクル**により、DelegationBench v4において**TPR（真陽性率）100%、FPR（偽陽性率）0%** を達成
- LLMを権限判断の主体とせず、決定論的な検証エンジンを採用することで、確率的な誤判断を排除

### 2. アイデンティティ・信頼・責任のトライアド

#### 2.1 従来アプローチの限界

古典的なゲーム理論的アプローチでは、エージェントは自己利益最大化を前提として設計されてきた。しかし、実際の人間社会における協調は、個人効用を超えた**向社会的考慮（Prosocial Considerations）**に依拠している。

#### 2.2 トライアドモデル

Deshmukh ら（2026）は、責任あるマルチエージェント行動を形作るコア要素として、**アイデンティティ・責任・信頼のトライアド**を初めて体系的に提示した。

**アイデンティティ（Identity）**
- **計算論的超越（Computational Transcendence）** の概念に基づく弾性的アイデンティティモデルを提案
- エージェントが自己の利益だけでなく他者の福祉を意思決定に組み込める

**信頼（Trust）**
- **主観的信頼**：アイデンティティに基づく（自己評価・自己認識）
- **客観的信頼**：経験に基づくもの（経験ベース）と評判に基づくもの（評判ベース）の二層構造

**責任（Responsibility）**
- エージェントが自律的に行動しつつも、その結果に対して説明責任を持つ設計

#### 2.3 繰り返し囚人のジレンマ（IPD）による検証

提案フレームワークは **Iterated Prisoner's Dilemma（IPD）** シミュレーションによって評価されており、向社会的行動と信頼形成の関係が定量的に分析されている。

### 3. 技術的・理論的な横断的課題

#### 意図の検証可能性

SentinelAgentのDCCが示すように、委任連鎖を通じた「意図保存」は**確率論的にしか保証できない**。これはLLMベースのエージェントが自然言語による曖昧な指示を解釈するという本質的性質に起因する。決定論的セキュリティ保証と確率論的AIの間のギャップは、マルチエージェントセキュリティの核心的課題である。

#### 鑑識可能性（Forensic Reconstructibility）

委任連鎖のすべてのステップを事後的に再構成できる能力は、説明責任・監査・インシデント対応において不可欠である。これはアイデンティティ・責任のトライアドが求める「責任の帰属」とも直結する。

#### オープン環境への適応

オープンなマルチエージェント環境では、事前に信頼関係を確立できない未知のエージェントとの相互作用が発生する。評判ベースの信頼モデルと動的なポリシー更新機構の組み合わせが有効なアプローチとして注目される。
