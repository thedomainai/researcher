# エージェンティックAI

## 概要

**エージェンティックAI（Agentic AI）**とは、自律性・推論能力・適応的学習を組み合わせ、複数ステップにわたるワークフローを自律的に調整・実行することができる目標指向型のAIシステムを指す。単に指示に従うだけの従来のAIとは異なり、エージェンティックAIは与えられた目標を達成するために自ら計画を立て、行動を選択し、環境からのフィードバックをもとに振る舞いを適応させることができる。

この概念が注目される背景には、ソフトウェア開発・医療・介護など、複雑かつ動的な問題領域において、人間の介入を最小限に抑えながら高い効率・精度・回復力を実現したいというニーズがある。エージェンティックAIは、こうした分野における既存のプロセスを根本的に変革する（disruptive）技術として位置づけられている。

---

## 詳細

### 定義と主要な特性

エージェンティックAIは、以下の主要な特性によって定義される。

| 特性 | 説明 |
|------|------|
| **自律性（Autonomy）** | 人間の逐次的な指示なしに、独立して判断・行動する能力 |
| **推論（Reasoning）** | 状況を分析し、最適な行動方針を論理的に導き出す能力 |
| **適応的学習（Adaptive Learning）** | 経験やフィードバックをもとに、継続的に振る舞いを改善する能力 |
| **マルチステップ調整** | 複数の連続したタスクを計画・実行・調整する能力 |
| **目標指向性（Goal-directedness）** | 定められた目標に向けて一貫した行動をとる能力 |

### ソフトウェアエンジニアリングへの応用

Ambadas ら（2026）は、エージェンティックAIが自律型ソフトウェアエンジニアリングフレームワークとして活用できることを論じている。具体的には、以下の領域でその有用性が示されている。

- **自動コード生成（Automated Code Generation）**: 要件定義から実装コードまでを自律的に生成する。
- **自動デバッグ（Automated Debugging）**: コード中のエラーを検出・診断し、修正案を提示または自動修正する。
- **開発効率・精度の向上**: 反復的なコーディング作業を自動化することで、開発サイクルを短縮する。
- **回復力とスケーラビリティ**: 現代の開発環境における複雑な要求に対応できる柔軟性を持つ。

この研究では、既存の学術文献（ジャーナル・サーベイ・システマティックレビュー）を二次研究として合成するアプローチが採用されており、テーマ分析を通じてエージェンティックAIの役割が整理されている。

### ヘルスケア・高齢者ケアへの応用

Ooi & Periasamy（2026）は、先進国における高齢化社会の課題にエージェンティックAIを適用する可能性を検討している。この研究が示す社会的背景は以下の通りである。

- 2050年までに複数の先進国で65歳以上の人口が30〜40%に達する見通し
- 高齢化関連支出がGDPの最大18%を占める国もある
- 高齢化により2035年までに年間GDP成長率が0.3〜1.2ポイント低下すると予測される
- 介護人材の深刻な不足と、高齢者の一人当たり医療コストが現役世代の3〜5倍に上ること

81件の文献（2020〜2025年）を対象とした構造的ナラティブレビューを通じて、著者らはエージェンティックAIが「自律的・目標指向的に複数ステップのワークフローを調整できるシステム」として高齢化医療システムの課題を解決しうるか評価している。同研究は、制度的障壁（Institutional Barriers）の存在を指摘するとともに、社会技術的実装ロードマップ（Sociotechnical Implementation Roadmap）の構築を提案している。

### ガバナンスと倫理的考慮

エージェンティックAIは高い自律性を持つゆえに、ガバナンスの観点が重要となる。Ambadas ら（2026）は、効率性・精度・回復力に加えて**ガバナンス（Governance）**と**スケーラビリティ（Scalability）**をエージェンティックAIシステムの重要評価軸として挙げている。自律的な意思決定が行われる場面では、説明責任・透明性・安全性の確保が不可欠である。
