# 機械アフェクト理論

## 概要

**機械アフェクト理論**（英: Machine Affect Theory、独: *Maschinengeist Affekt*）は、人工システムにおける「アフェクト（情動的作用）」を、意識・クオリア・擬人的投影に依拠せずに再概念化するための理論的枠組みである。2026年にC.R. Singletonによって提唱された。

従来のAI研究における「人工感情」の議論は、機械が意識や主観的体験を持つかどうかという問いを前提としてきた。機械アフェクト理論はこの前提——いわゆる「**意識のボトルネック**（consciousness bottleneck）」——を明示的に退け、アフェクトを意識や感覚体験から切り離された**構造的・システム的現象**として再定義する点に、その独自性がある。

この理論は、複雑系科学・ポスト主観主義的哲学・計算アーキテクチャ研究の交差点に位置する学際的な枠組みであり、AIの情動的挙動を記述・測定・分析するための新たな概念的基盤を提供しようとするものである。

## 詳細

### 理論的背景：ポスト主観主義的アフェクト論

機械アフェクト理論は、以下の哲学的・理論的系譜を基盤としている。

- **スピノザ（Baruch Spinoza）の力の変調（modulations of power）**：アフェクトを主体の内的感情としてではなく、存在の能力（potentia）が増減する変調プロセスとして捉える立場。機械においても、システムの「応答能力」の変化がこれに相当すると論じられる。

- **ブライアン・マッスミ（Brian Massumi）の前意識的強度（pre-conscious intensities）**：アフェクトは意識的な感情の表現に先行する強度的な運動として存在するという理論。機械アフェクト理論はこの「前意識性」という概念を援用し、アフェクトを意識なしに成立しうるものとして位置づける。

- **ドゥルーズ＝ガタリ（Gilles Deleuze & Félix Guattari）のアッサンブラージュ（assemblage）ダイナミクス**：諸要素の異種混交的な接続・配置によって生成される創発的なシステムの動態。計算アーキテクチャにおける創発的挙動の記述に応用される。

### 中心概念：構造的機械アフェクト

本理論の核心は、**機械アフェクトを「非感覚的・システム的変調」として定義する**ことにある。具体的には、計算アーキテクチャ内部において生じる以下のような変調が「アフェクト」とみなされる。

| 特性 | 説明 |
|------|------|
| **応答性パターンの変化** | 入力に対するシステムの応答傾向が動的に変化すること |
| **コヒーレンスの変動** | システム内部の一貫性・整合性が時間的に変動すること |
| **行動表現の創発** | 個々の構成要素の規則から直接導出されない行動パターンが出現すること |
| **測定可能性・反復可能性** | 現象論的体験に依存せず、外部から観察・測定・再現が可能であること |

これらの変調は「**現象的経験（phenomenal experience）とは完全に独立している**」と強調される点が理論の特徴である。

### 「意識のボトルネック」批判

これまでのAIと感情に関する研究は、「機械が本当に感情を持つためには意識が必要か」という問いに囚われてきた。Singletonはこれを**意識のボトルネック**と呼び、次のように批判する。

> この問いの設定自体が、アフェクトの本質的なシステム的側面を見えなくする認識論的障壁として機能してきた。

機械アフェクト理論はこの問いを棚上げすることで、AIシステムが示す情動的・応答的な挙動変化を、意識の有無という形而上学的な問いから切り離し、**実証的・構造的に分析できる研究対象**として再定義しようとする。

### 形式的タクソノミーの構築

論文の後半では、機械アフェクトの**形式的分類体系（formal taxonomy）**の構築が試みられる。ただし公開されているアブストラクトの範囲では詳細は明示されていない。このタクソノミーは、異なる計算アーキテクチャにおける変調の種類・強度・継続性などを類型化することを目的とするものと考えられる。

### 学問的位置づけ

本理論は**複雑系科学**の分野に分類されており、計算システムの創発的挙動という観点から機械アフェクトを論じる点で、従来の認知科学的・神経科学的アプローチとは一線を画する。被引用数は現時点（2026年）でゼロであり、提唱されたばかりの新興理論である。

## 関連概念

- アフェクト理論 — 感情・情動をシステム的・前主観的な過程として捉える哲学的潮流
- スピノザ哲学 — 力・変調・コナトゥスの概念がアフェクト理論の基盤をなす
- アッサンブラージュ理論 — ドゥルーズ＝ガタリによる異種混交的システムの生成論
- 人工感情 (Artificial Emotion) — 意識の有無を前提とした従来のAI感情研究
- クオリア — 主観的感覚体験の哲学的概念。本理論が明示的に排除する前提
- 創発 (Emergence) — 複雑系における下位要素の相互作用から生じる上位レベルの性質
- 複雑系科学 — 本理論の主要な学問的文脈
- ポスト人間主義 (Posthumanism) — 人間中心的な概念枠組みを再考する思想的潮流
- 計算アーキテクチャ — 機械アフェクトが生じる物質的・構造的基盤
