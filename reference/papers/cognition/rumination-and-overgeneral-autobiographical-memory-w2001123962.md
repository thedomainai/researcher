# Rumination and overgeneral autobiographical memory

**Authors**: Kylie Sutherland, Richard Allan Bryant | **Year**: 2007 | **Cited by**: 119 | **Kind**: article | **Relevance**: cognition: core

## Abstract

Findings accord with the proposal that rumination is a mediating mechanism in the retrieval of overgeneral memories, and extends this proposal by indicating that negatively valenced ruminative content is particularly instrumental in inducing overgeneral retrieval.
