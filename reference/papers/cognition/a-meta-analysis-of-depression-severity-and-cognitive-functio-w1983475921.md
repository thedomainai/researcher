# A meta-analysis of depression severity and cognitive function

**Authors**: Lisa M. McDermott, Klaus P. Ebmeier | **Year**: 2009 | **Cited by**: 976 | **Kind**: meta_analysis | **Relevance**: cognition: core

## Abstract

Significant correlations between depression severity and cognitive performance were found in the domains of episodic memory, executive function, and processing speed, but not for semantic memory or visuo-spatial memory.
