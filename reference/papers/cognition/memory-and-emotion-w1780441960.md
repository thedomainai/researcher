# Memory and Emotion

**Authors**: (unknown) | **Year**: 2004 | **Cited by**: 327 | **Kind**: book | **Relevance**: cognition: supporting

## Abstract

Abstract Understanding the interplay between memory and emotion is crucial for the work of researchers in many arenas—clinicians, psychologists interested in eyewitness testimony, psychobiologists, to name just a few. This book spans all these areas and brings them together into one volume. The book provides a sophisticated profile of our current understanding of how memory is shaped both by emotion and emotional disorder. The diverse list of topics includes the biology of traumatic memory, the memory disorders produced by depression, anxiety, and schizophrenia, the nature of emotional memory both in children and the elderly, and the collective memory processes at work in remembering the Holocaust.
