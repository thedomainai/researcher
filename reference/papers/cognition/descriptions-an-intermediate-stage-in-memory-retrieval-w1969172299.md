# Descriptions: An intermediate stage in memory retrieval

**Authors**: Donald A. Norman, Daniel G. Bobrow | **Year**: 1979 | **Cited by**: 393 | **Kind**: article | **Relevance**: cognition: supporting

## Abstract

This paper presents a semiformal model of memory retrieval based upon the notion of variable levels of specification, and postulates that retrieval starts with a description of the desired information as an initial specification of the records sought from memory.
