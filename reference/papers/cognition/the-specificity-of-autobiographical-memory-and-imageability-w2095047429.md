# The specificity of autobiographical memory and imageability of the future

**Authors**: James M. Williams, Nick C. Ellis, Claire Tyers, Helen Grania Healy, Gillian Rose, Andrew K. MacLeod | **Year**: 1996 | **Cited by**: 527 | **Kind**: article | **Relevance**: cognition: supporting

## Abstract

It is suggested that the association between memory retrieval and future imaging arises because the intermediate descriptions used in searching autobiographical memory are also used to generate images of possible events in the future.
