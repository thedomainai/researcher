# Disruptions in autobiographical memory processing in depression and the emergence of memory therapeutics

**Authors**: Tim Dalgleish, Aliza Werner‐Seidler | **Year**: 2014 | **Cited by**: 294 | **Kind**: review | **Relevance**: cognition: core

## Abstract

Memory therapeutics is the development of novel clinical techniques that target memory difficulties in those with emotional disorders, including MEmory Specificity Training, positive memory elaboration, memory rescripting, and the method-of-loci (MoL).
