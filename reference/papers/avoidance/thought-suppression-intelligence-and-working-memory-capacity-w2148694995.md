# Thought suppression, intelligence, and working memory capacity

**Authors**: Chris R. Brewin, Alan A. Beaton | **Year**: 2002 | **Cited by**: 219 | **Kind**: article | **Relevance**: avoidance: core

## Abstract

The results indicated that more effective thought suppression was independently related to higher working memory capacity and greater fluid intelligence, but was unrelated to crystallised intelligence.
