# A MODULAR BENCHMARKING FRAMEWORK FOR EVALUATING LLM-BASED AGENT APPLICATIONS

**Authors**: Karthik Perikala | **Year**: 2026 | **Cited by**: 29 | **Kind**: article | **Relevance**: evaluation: core; agents: core

## Abstract
